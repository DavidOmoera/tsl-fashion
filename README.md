TSL E-Commerce Website
A responsive luxury e-commerce platform built in 7 days using HTML and CSS, and Firebase. Features include a dynamic cart modal, secure Flutterwave payment integration, and real-time inventory management. Optimized for UX with smooth animations and mobile-first design.
- Tech Stack: React, HTML CSS, JavaScript, Firebase, Flutterwave
- Key Features**:
  - Responsive product pages and cart modal with animations
  - Secure payment processing with HTTPS/TLS
  - Real-time stock updates to prevent overselling
- Live Demo: tsl-fashion.web.app
- Development Process*:Used GitHub Copilot for code suggestions, accelerating development by 20%.
